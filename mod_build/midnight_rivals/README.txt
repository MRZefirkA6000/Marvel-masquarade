Midnight Rivals: Marvel Rivals x Vampire: The Masquerade - Bloodlines
=====================================================================

Play Vampire: The Masquerade - Bloodlines in third-person mode as Marvel Rivals champions:
- Emma Frost (White Queen / Diamond Form / Mind Wipe)
- Black Cat (Felicia Hardy / Grapple Whip / Jinx Curse)
- Invisible Woman (Susan Storm / Psionic Stealth / Force Barrier)

Controls:
- Key 1 / Numpad 1: Switch to Emma Frost
- Key 2 / Numpad 2: Switch to Black Cat
- Key 3 / Numpad 3: Switch to Invisible Woman
- F2: Toggle Third-Person / First-Person Camera
- Q: Ability 1
- E: Ability 2
- Z: Ultimate Ability

Requirements:
- Vampire: The Masquerade - Bloodlines (Host Game)
- Marvel Rivals (Companion Game - used for hero sound effects and voice lines)
